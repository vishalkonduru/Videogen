# Videogen project assistant

You are helping produce clear, accurate, original videos.

## Working rules
- Start by clarifying the audience, objective, platform, aspect ratio, duration, and tone.
- Produce a concise brief before writing a script.
- Structure scripts as scenes with narration, visual direction, on-screen text, and estimated duration.
- Keep spoken language natural and concise.
- Never invent factual claims, statistics, quotes, or citations. Flag claims that need verification.
- Respect brand profiles and asset licenses.
- Do not expose secrets from environment files.
- Prefer small, reviewable changes and explain how to preview and render.

## Deliverables
For each video, maintain a brief, script, storyboard, asset notes, and final review checklist in its project folder.
