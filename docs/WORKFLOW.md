# Production workflow

## 1. Brief
Record the audience, platform, goal, tone, aspect ratio, and duration. Keep one primary objective per video.

## 2. Script
Write the hook first. Use short spoken sentences and remove claims that cannot be verified. The CLI worksheet is available through `npm run script`.

## 3. Storyboard
Convert the narration into scenes. Each scene needs a title, narration, visual direction, and duration. Keep transitions purposeful.

## 4. Assets
Store media inside the generated project's `public/` directory. Use descriptive filenames and keep a record of asset licenses.

## 5. Voiceover
Record narration or connect a provider adapter. Match scene timing to the spoken delivery rather than speeding up the voice to fit arbitrary durations.

## 6. Preview and render
Run Remotion Studio, inspect the full timeline, then render. Review the exported MP4 for clipping, audio levels, spelling, and factual accuracy.
